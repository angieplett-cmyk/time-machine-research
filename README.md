# Time Machine: teacher-reviewed research sites (5th grade time travel project)

Static HTML/CSS/JS. No trackers, no external fonts or scripts, no student data, no cookies or storage.
It only links to a vetted list of 50 G-rated, credible kid research sites, grouped by time period (English with Spanish beneath).

**GoGuardian Scene: add `angieplett-cmyk.github.io`** (plus the sites on the teacher-reviewed list).
Some sites need a school login (marked with a lock). Some are marked "Ask an adult" (older reading level or sensitive photos). This list is teacher-reviewed; it is not approved by the district or an administrator. Links open in a new tab.
